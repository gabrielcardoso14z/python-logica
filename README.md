# Python: Lógica de Programação

Exercícios do meu estudo de lógica de programação com Python.
Estou aprendendo desde o básico e vou atualizando este repositório conforme avanço.

## Exercícios

| Arquivo | O que faz | Conceito |
|---|---|---|
| `primeiro.py` | Pede nome e idade e calcula o ano de nascimento | `input`, `int()`, `print` |
| `convidados.py` | Diz se a pessoa é criança, adolescente ou adulta | `if`, `elif`, `else` |
| `tabuada.py` | Mostra a tabuada do número digitado | `for`, `range` |
| `soma.py` | Soma todos os números de 1 até n | `for`, acumulador |
| `par_impar.py` | Diz se um número é par ou ímpar | `%`, `if`, `else` |
| `adivinha.py` | Jogo de adivinhar um número, com contador de tentativas | `while`, `if`, `elif`, contador |

## Como rodar

1. Instale o Python (python.org).
2. Abra o arquivo no VS Code ou no terminal.
3. Rode com: `python nome_do_arquivo.py`
